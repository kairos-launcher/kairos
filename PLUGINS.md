# Plugins

The plugin documentation moved to the docs site, **https://kairos-launcher.github.io/kairos/**. Its
sources are in [`docs/`](docs/).

Using plugins:

- [All plugins](https://kairos-launcher.github.io/kairos/plugins/): what each one does, its commands and
  settings, and managing plugins (`plugin …`)
- [Configuration](https://kairos-launcher.github.io/kairos/guide/configuration): `config.toml`, plugin
  settings, secrets, proxy
- [Custom actions](https://kairos-launcher.github.io/kairos/plugins/actions) and
  [script commands](https://kairos-launcher.github.io/kairos/plugins/scripts)
- [AI tools (MCP)](https://kairos-launcher.github.io/kairos/plugins/ai#tools-mcp)

Writing plugins:

- [Getting started](https://kairos-launcher.github.io/kairos/develop/writing-plugins): architecture,
  how plugins work, `plugin.toml`, settings, icons
  ([source](docs/develop/writing-plugins.md))
- [Protocol reference](https://kairos-launcher.github.io/kairos/develop/protocol)
  ([source](docs/develop/protocol.md))
- [Remote plugins (HTTPS)](https://kairos-launcher.github.io/kairos/develop/remote-plugins)
  ([source](docs/develop/remote-plugins.md))
- [Bundled plugins in Rust](https://kairos-launcher.github.io/kairos/develop/bundled-plugins)
  ([source](docs/develop/bundled-plugins.md))
- Per language, with examples: [Node.js](https://kairos-launcher.github.io/kairos/develop/nodejs),
  [Rust](https://kairos-launcher.github.io/kairos/develop/rust),
  [Go](https://kairos-launcher.github.io/kairos/develop/go),
  [Python](https://kairos-launcher.github.io/kairos/develop/python); the examples are in
  [`examples/plugins/`](examples/plugins/)
