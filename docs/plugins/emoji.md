# Emoji

Find an emoji and copy it. Id `emoji`, triggers `:` and `emoji `.

## Commands

| Type | Does |
|---|---|
| `:thumbs`, `:tada` | Emoji whose name or keywords match. |
| `:red heart`, `emoji party` | Every word must match a word of the name or a keyword. |

| Key | Does |
|---|---|
| **Enter** | Copy the emoji. |
| **Tab** | Copy name, Copy code points. |

About 1900 emoji with Unicode names and CLDR keywords.

## Settings

| Key | Type | Default | Meaning |
|---|---|---|---|
| `skin_tone` | choice | `""` | For emoji that have skin tones: `light`, `medium-light`, `medium`, `medium-dark`, `dark`. Empty: the default yellow. |

## Notes

Rows show colour images from the system's emoji font (Noto Color Emoji, Apple Color Emoji). On
Windows, whose Segoe UI Emoji has no images, the tile shows the emoji as text in one colour.
